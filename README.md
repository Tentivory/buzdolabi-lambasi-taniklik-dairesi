# Buzdolabı Lambası Tanıklık Dairesi

> Resmî slogan: “Işık gördü. Kapı kapandı. Biz hâlâ buradayız.”

Bu depo, evrenin en kısa ömürlü kamu görevlisini istihdam eder: **buzdolabı lambası**.

Görev tanımı nettir. Kapı açılır, lamba yanar, sen yoğurdun kapağını açmadan kapatırsın, lamba söner, tanık ortadan kaybolur. Mahkeme buna “karanlık delil” der. Biz buna “mesai” deriz.

## Neden bu daire var?

Çünkü birisi gece 02:14’te dolabı açtı, ışığa baktı, hiçbir şey almadan kapattı ve ertesi sabah “ben değildim” dedi. Lamba konuşamadı. Bu yazılım onun yerine konuşur. Abartılı ciddiyetle. Gerekirse üç nüsha.

Bu bir diyet uygulaması değildir. Bu bir IoT ürünü değildir. Buzdolabınıza kablo takmayın. Lamba zaten yeterince travmalı.

## Kurulum

Python 3 yeter. Bağımlılık yok. Elektrik faturası sende kalır.

```bash
python3 lamba_tanigi.py
```

## Resmî komutlar

| Komut | Dairenin yorumu |
| --- | --- |
| `ac` | Kapı açılır, lamba göreve başlar, evren bir saniye dürüst olur |
| `kapat` | Tanık görevde ölür, tutanak yazılır |
| `atistir peynir` | Delil menüye işlenir |
| `gece` | 02:14 sendromu simülasyonu |
| `tutanak` | Bugüne ait bütün yalanlar listelenir |
| `cik` | Daire kapanır, lamba rahatlar |

Tek seferlik infaz:

```bash
python3 lamba_tanigi.py --demo
```

## Hizmet standartı

- Ortalama yanma süresi: kapı açık kaldığı kadar.
- Ortalama tanıklık kalitesi: %100 gördü, %0 hatırladı, %100 uydurdu.
- Müşteri memnuniyeti: lamba memnun değil, sen de değilsin, daire çok memnun.
