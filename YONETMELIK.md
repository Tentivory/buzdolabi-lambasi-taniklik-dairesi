# Taniklik Yonetmeligi, Madde 0

1. Lamba yalnizca kapi acikken memurdur.
2. Kapi kapaninca memur degil, anidir.
3. Ani tutanaga gecmezse hic olmamistir, kahvalti haric.
4. Peynir dilimi ifade vermek zorunda degildir.
5. Bu yonetmelik kendi kendini ciddiye alir, sen alma.
